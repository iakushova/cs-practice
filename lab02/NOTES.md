# Git: рабочая папка, индекс и коммит

## Рабочая папка

Рабочая папка — это файлы проекта, с которыми я работаю непосредственно на компьютере. Здесь я создаю, изменяю и удаляю файлы.

## Индекс

Индекс — это промежуточная область, куда я добавляю изменения, которые хочу включить в следующий коммит. Команда git add помещает изменения в индекс.

## Коммит

Коммит — это сохранённая в истории Git версия подготовленных изменений. Он содержит информацию о том, что было изменено, когда и кем.
## Git и GitHub

Git — это система контроля версий, которая работает с историей изменений проекта на компьютере.

GitHub — это интернет-сервис, который позволяет хранить Git-репозитории удалённо и работать с ними совместно.

Git может работать без GitHub. GitHub использует Git для хранения и публикации репозиториев в интернете.
## Использованные команды

### git status

Показывает текущее состояние рабочей папки и индекса. С его помощью можно увидеть изменённые, новые и подготовленные файлы.

### git diff

Показывает изменения в рабочей папке, которые ещё не были добавлены в индекс.

### git diff --staged

Показывает изменения, которые уже находятся в индексе и будут включены в следующий коммит.
